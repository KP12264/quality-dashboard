## Notes

- `QD_OPS_WRITE_ENABLED` / `?qdOpsWrite=1` only enable the buttons. The boundary is the rules: admin role + an own START record in qdOpsLog (immutable, server time) for the same action within 12 h. A direct SDK call without a run is refused (tested).
- Concurrent reconcile of one slot by two admins: 1 succeeded, 1 refused (changed meanwhile); exactly one RECONCILE event.
- Reconcile racing a Leader save: reconcile rejected, save fulfilled; after (re-)run the slot is consistent.
- Same baseline run twice at once: 6 + 0 created = 6 slots; no duplicates, no failures.
