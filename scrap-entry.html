Accepts .csv or .xlsx — both the simple format (Date, Shift, Line, Model, Defect, Qty, optionally Remark/Cause) and the rich format (Material, MaterialName, Quantity, Location, Problem, Cause, Solution, Price, Amt, Model, Date, Line, shift2) are supported automatically. For a multi-sheet workbook, the sheet named Data is used if present, otherwise the first sheet. Date/Shift/Line prefer the clean Date/shift2/Line columns; a combined "25 Jul 2026 #D"-style value or Location text is used only as a fallback when those are missing. Model is checked against Production V2's real plan for that date/line/shift — an unmatched model is flagged, not silently imported. Rows matching an existing scrapLogs record are flagged as duplicates and excluded by default.
